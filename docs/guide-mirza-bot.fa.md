# راهنمای اتصال میرزا به پنل نمایندگی با توکن API

این راهنما توضیح می‌دهد چطور ربات میرزا (یا هر ربات سازگار با 3x-ui) را به داشبورد وصل کنید تا خریداران، سرویس را **مستقیم از همین پنل** بخرند و دریافت کنند.

> نماینده‌ها می‌توانند همین آموزش را داخل خود پنل هم ببینند:
> **تنظیمات حساب ← کارت «اتصال فروش به میرزا» ← راهنمای قدم‌به‌قدم**
> یا از این آدرس: `/guide/mirza-bot`

## نحوه کار به چه شکلی است؟

```text
خریدار (تلگرام)
   │  سرویس را از ربات شما می‌خرد
   ▼
ربات میرزا
   │  پرداخت را تأیید می‌کند و به پنل وصل می‌شود
   ▼
داشبورد نمایندگی (پل 3x-ui)
   │  کاربر را می‌سازد و سهمیه را از پول ترافیک شما کم می‌کند
   ▼
پنل(های) 3x-ui  ──►  لینک سابسکریپشن برای خریدار ارسال می‌شود
```

ربات با **توکن API مخصوص نمایندگی شما** وارد می‌شود؛ فقط اینباندهای مجاز همین حساب و سقف پول ترافیک شما برای آن اعمال می‌شود. روش زیر با قرارداد میرزا ۰٫۸٫۱ تطبیق داده شده است.

## مرحله ۱ — سوییچ اتصال را روشن کنید

وارد پنل نمایندگی شوید ← تب **«تنظیمات حساب»** ← کارت **«اتصال فروش به میرزا»**.
سوییچ را روشن کنید و دکمه **«ذخیره و اتصال ربات»** را بزنید. جعبه سبزِ تنظیمات اتصال نمایش داده می‌شود:

برای فروش، واردکردن توکن تلگرامِ بخش اعلان‌ها لازم نیست.

## مرحله ۲ — توکن API اتصال فروش را بسازید

از جعبه سبز:
- **آدرس پنل (Panel URL)** — با دکمه کپی کنارش
- **نام کاربری** — همان نام کاربری داشبورد شما
- **توکن API اتصال فروش** — روی «ساخت توکن API» بزنید و همان بار آن را کپی کنید

## مرحله ۳ — در ربات میرزا پنل اضافه کنید

در میرزا: **مدیریت پنل‌ها ← افزودن پنل جدید ← ثنایی / 3x-ui** با نوع `x-ui_single`.
آدرس پنل و توکن API را وارد کنید. در نسخهٔ ۰٫۸٫۱، `password_panel` محل همین توکن است؛ اگر نام کاربری هم خواست، نام همین نمایندگی را بگذارید.

## مرحله ۴ — شناسه اینباند (inboundid)

در داشبورد، دکمه **«بررسی لوکیشن‌های قابل فروش»** را بزنید. فقط شناسه‌های مجاز، موجود و آنلاین نمایش داده می‌شوند:

شناسه‌های دلخواه را در انتخاب اینباندهای پنل/محصول میرزا وارد کنید. نسخهٔ جدید، `inbounds` چندگانه مانند `[17, 21]` می‌گیرد؛ نسخه‌های قدیمی `inboundid` تکی دارند.

## مرحله ۵ — لینک ساب (linksubx)

ربات لینک اشتراک خریدار را به شکل `linksubx/شناسه` می‌سازد. مقدار `linksubx` را از جعبهٔ اتصال داشبورد کپی کنید؛ روی دامنهٔ اصلی:

```text
https://npanel.softarg.ir/api/s
```

لینک نهایی خریدار به شکل `https://npanel.softarg.ir/api/s/<شناسه>` خواهد بود. مسیر `/api/s` را همراه آدرس وارد کنید.

## مرحله ۶ — ذخیره و فروش

حجم بسته‌ها را عدد صحیح گیگابایت و حداقل ۱ گیگ تنظیم و ذخیره کنید؛ کسری گیگ پشتیبانی نمی‌شود. از این لحظه:
- هر خرید در ربات، به‌صورت خودکار روی همین پنل کاربر می‌سازد
- سهمیه خریدار از **پول ترافیک** شما کسر می‌شود
- لینک سابسکریپشن برای خریدار ارسال می‌شود
- اعلان ساخت کاربر، مصرف ۸۰٪+ و انقضای نزدیک به تلگرام شما می‌آید
- مصرف کاربران حتی بعد از **حذف یا ریست ترافیک** به‌صورت قطعی ثبت می‌شود و قابل بازیابی نیست

## جدول کامل فیلدها

| فیلد در ربات میرزا | مقداری که وارد کنید |
|---|---|
| `url_panel` / آدرس پنل | آدرس پنل از جعبه سبز داشبورد (دکمه کپی) |
| `username_panel` / نام کاربری | نام کاربری داشبورد شما |
| توکن پنل / `password_panel` | توکن API اتصال فروش، ساخته‌شده در نمایندگی |
| `inbounds` / `inboundid` | شناسه‌های نمایش‌داده‌شده در فهرست زندهٔ لوکیشن‌ها |
| `linksubx` / لینک ساب | آدرس جعبهٔ اتصال؛ روی دامنهٔ اصلی `https://npanel.softarg.ir/api/s` |
| `type` / نوع پنل | `x-ui_single` (ثنایی / 3x-ui) |

## سوالات پرتکرار

**فروش ربات چقدر از پول من کم می‌کند؟**
دقیقاً به اندازه سهمیه خریدار. مصرف واقعی حتی بعد از حذف یا ریست هم قطعی ثبت می‌شود و به پول برنمی‌گردد.

**ربات به پنل‌های دیگر من دسترسی دارد؟**
خیر. فقط اینباندهایی که برای همین حساب اختصاص یافته و فقط تا سقف پول ترافیک شما.

**تست اتصال ربات خطا می‌دهد؟**
سوییچ را روشن و ذخیره کنید، توکن API فروش را در فیلد توکن پنل میرزا بگذارید و آدرس پنل و ساب را از همین داشبورد کپی کنید. پس از تعویض توکن، مقدار جدید را در میرزا جایگزین کنید.

**چطور دسترسی ربات را قطع کنم؟**
توکن را لغو/تعویض کنید یا سوییچ را خاموش و ذخیره کنید. کلید قبلی بلافاصله نامعتبر می‌شود و با روشن‌کردن مجدد زنده نمی‌شود. تغییر تنظیمات ورود هم کلید قبلی را از کار می‌اندازد.

توکن فروش فقط هنگام ساخت نمایش داده می‌شود و در دیتابیس فقط اثر انگشت آن ذخیره می‌شود. توکن اعلان تلگرام، در صورت استفاده، جداگانه رمزنگاری می‌شود. ربات مجوز روتینگ، پروتکل و تنظیمات زیرساخت نمی‌گیرد.

ورود قدیمی `/api/bridge/USERNAME/login` برای کلاینت‌های مبتنی بر نشست حفظ شده، اما نشست آن ۲۴ساعته است؛ میرزا با روش API Token باید از کلید مخصوص اتصال فروش استفاده کند.
