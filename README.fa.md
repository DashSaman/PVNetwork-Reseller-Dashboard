# داشبورد نمایندگی PVNetwork برای 3x-ui

> 🇬🇧 [English version](README.md) | 🇮🇷 فارسی

[![نصب](https://img.shields.io/badge/نصب-یک%20خط-10615b)](#-نصب-سریع)

داشبورد نمایندگی سلف‌هاست‌شده برای یک یا چند سرور 3x-ui موجود — پول ترافیک، مدیریت چندپنلی، فروش با ربات میرزا، برند اختصاصی، ورود دومرحله‌ای، پرتال سابسکریپشن و حسابداری سخت‌گیرانه.

## ⚡ نصب سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DashSaman/PVNetwork-Reseller-Dashboard/main/install.sh)
```

همین یک خط. نصب‌کننده نام دامنهٔ پنل را می‌پرسد، Docker، Apache TLS، Let's Encrypt و دیتابیس را خودکار راه می‌اندازد — بدون دست‌زدن به سرورهای 3x-ui، Xray یا سرویس‌های دیگر شما.

## 🔗 راه‌اندازی ربات میرزا (قدم‌به‌قدم)

راهنمای کامل: [docs/guide-mirza-bot.fa.md](docs/guide-mirza-bot.fa.md) یا صفحه `/guide/mirza-bot` در پنل.

| قدم | عمل |
|---|---|
| ۱ | تنظیمات حساب ← «ربات میرزا پنل» ← سوییچ را روشن و ذخیره کنید |
| ۲ | آدرس پنل، نام کاربری و رمز را از جعبه سبز کپی کنید |
| ۳ | در ربات میرزا: پنل‌ها ← افزودن پنل ← نوع: `x-ui` |
| ۴ | آدرس، نام کاربری و رمز را وارد کنید |
| ۵ | «تست اتصال ربات» را بزنید — شناسه اینباند زیر دکمه نمایش داده می‌شود |
| ۶ | همان عدد را در فیلد `inboundid` ربات وارد کنید |
| ۷ | `linksubx` را روی آدرس سابسکریپشن 3x-ui خودتان تنظیم کنید |
| ۸ | ذخیره کنید — فروش‌ها از همین پنل انجام می‌شود |

## 🛡️ امنیت و حسابداری

| قابلیت | وضعیت |
|---|---|
| نمایندهٔ محدود → کاربر نامحدود | ✅ غیرممکن (server-side) |
| دور زدن پول (حذف/ریست/ساخت مجدد) | ✅ مسدود (مصرف قطعی) |
| over-spend هم‌زمان | ✅ قفل اتمیک |
| شکست جزئی چندپنلی | ✅ ژورنال عملیات + retry |
| حسابداری crash-safe | ✅ commit در یک تراکنش |
| Idempotency ساخت | ✅ هدر `Idempotency-Key` |
| رزرو دلتای ویرایش | ✅ ماندگار |
| مصرف کانونی چندپنلی | ✅ تک‌منبع |
| تصادم subId | ✅ ایندکس یکتا |
| حذف ناامن نماینده | ✅ 409 |
| پول زیر تعهدات | ✅ 409 + override صریح |

## 🏗️ معماری

```text
مرورگر / Cloudflare → Apache :443 → Docker (127.0.0.1:31080) → پنل‌های خارجی 3x-ui
                                                            ↘ SQLite (volume)
```

## 📦 ساختار نصب

```text
/opt/pv-reseller/
├── app/          # سورس (Git)
├── data/custom.db
├── backup/
├── .env
└── INITIAL_CREDENTIALS.txt
```

## 🔄 به‌روزرسانی

```bash
bash /opt/pv-reseller/app/update.sh
```

امن: بکاپ ← مایگریشن افزودنی ← بیلد کاندید ← چک سلامت ← تعویض. Rollback خودکار در صورت خطا.

## 📋 نیازمندی‌ها

- Ubuntu/Debian، دسترسی root، ۴ گیگ فضا
- دامنه با DNS به سرور شما
- پورت‌های 80 و 443 آزاد
